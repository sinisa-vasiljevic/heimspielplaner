# Heimspielplaner V45

Lade `index.html`, `manifest.webmanifest` und `version.json` gemeinsam in das Stammverzeichnis des GitHub-Repositorys hoch.

Die Datei `version.json` wird ohne Browser-Cache abgefragt. In der Kopfzeile muss danach `VERSION 45` stehen.

Vor spaeteren Updates kann im Reiter **Import/Export** eine vollstaendige JSON-Sicherung erstellt werden.
