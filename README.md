# Heimspielplaner V45.1

Diese vier Dateien gemeinsam in das Stammverzeichnis des GitHub-Repositorys hochladen und vorhandene Dateien ersetzen:

- index.html
- manifest.webmanifest
- version.json
- README.md

Nach dem GitHub-Upload muss in der Kopfzeile `VERSION 45.1` erscheinen. Die Datei `version.json` wird ohne Browser-Cache geladen.

V45.1 korrigiert die mobile Ausrichtung der Datums-, Zeit- und Auswahlfelder. Zweierspalten besitzen jetzt identische Breiten, einheitliche Feldhöhen und feste Labelbereiche. Das SGV-Auswahlfeld nutzt die komplette Breite.
